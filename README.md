# SMG Media — portfolio rolek

## Pliki
- `index.html` — treść strony i tytuły projektów
- `style.css` — wygląd i układ responsywny
- `script.js` — odtwarzanie rolek w oknie
- `videos/` — tu dodaj pliki MP4

## Dodawanie filmów
Wgraj do `videos/` pliki `reel-01.mp4`, `reel-02.mp4`, `reel-03.mp4`, `reel-04.mp4`.
W HTML możesz zmienić tytuły `Project 01` itd. na nazwy projektów. Zmień również adres e-mail `hello@smgmedia.pl` na swój.

Zalecenia: MP4 (H.264/AAC), pionowe 9:16, możliwie zoptymalizowane pliki. Nie dodawaj dużej liczby ciężkich filmów do repozytorium — GitHub ma limity rozmiaru plików i repozytoriów.

## Publikowanie przez GitHub Pages
1. Utwórz publiczne repozytorium `portfolio` na koncie `smg-media`.
2. Wgraj zawartość tego folderu do głównego katalogu repozytorium (tak, aby `index.html` był na samym wierzchu).
3. Wejdź w **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz branch `main` i folder `/(root)`, potem **Save**.
6. Po zakończeniu publikacji strona będzie dostępna pod `https://smg-media.github.io/portfolio/`.

Jeśli nazwa repozytorium lub nazwa użytkownika będzie inna, adres strony też będzie inny.
